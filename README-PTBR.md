## Projetos em destaque

### Keilinks — LLM PT-BR autoral
[**github.com/Camillox2/Keilinks**](https://github.com/Camillox2/Keilinks)

Projeto de pesquisa e engenharia em modelos de linguagem locais. O **Keilinks Core 380M** não é apenas um fine-tuning de outro LLM: a arquitetura Transformer principal é implementada no próprio projeto e os pesos são inicializados e treinados pelo pipeline do Keilinks.

- Aproximadamente **380 milhões de parâmetros**.
- Transformer decoder próprio em **PyTorch**.
- Tokenizador com vocabulário de **32k**.
- **24 camadas**.
- **GQA, RoPE, RMSNorm, SwiGLU e QK-Norm**.
- KV cache e contexto de **8.192 tokens**.
- Pipeline próprio de **pré-treinamento + SFT conversacional**.
- Limpeza, deduplicação e rastreamento de proveniência dos dados.
- Modelos externos podem atuar apenas como **teacher/critic** em uma parcela limitada dos dados sintéticos, sem substituir os pesos do Core.
- Treinamento local otimizado para **RTX 5050 Laptop 8 GB**, com BF16/TF32, AdamW 8-bit, gradient checkpointing e `torch.compile`.
- Ecossistema com **RAG local, grounding web, memória isolada, API, avaliações e testes de regressão**.
